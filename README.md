## 每章三種模式

1. **考點速記** — 一行一個考點，附講義頁碼；紅底方塊是必考核心
2. **連連看** — 配對成功會跳出解釋
3. **題目練習** — 英文單選，每個選項都有中文詳解與頁碼，可只重做答錯的題目

## 使用方式

每個檔案都是獨立的 HTML，不需要任何建置工具或相依套件。

- 直接開啟 `index.html`
- 或用 GitHub Pages 發布後線上使用

作答進度存在瀏覽器的 localStorage，換裝置不會同步。
