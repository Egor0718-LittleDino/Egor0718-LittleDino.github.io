整章大綱

  1. 24.1 染色體元件
    1. 基因:編碼最終產物(polypeptide 或功能性 RNA)的全部 DNA;350 aa 需 1,050 bp p.5–6
    2. 基因體大小
      • E. coli:環狀 4,641,652 bp,長約 1.7 mm;plasmid 帶 β-lactamase 傳抗藥性 p.9
      • 人類:46 條,二倍體細胞 DNA 約 2 m p.10
      • mtDNA:環狀 16,569 bp;>95% 粒線體蛋白由核編碼;密碼不完全相同 國考 p.11–13
    3. Intron / exon:exon 只佔 1.5%;細菌很少有 intron,histone 基因沒有 p.14
    4. 重複序列:satellite DNA(<10 bp,~3%)在 centromere、telomere p.15
    5. 線性染色體三元件:centromere(接紡錘絲)、telomere(TTAGGG,telomerase 補)、origin;primer 不是 國考 p.15–19
  2. 24.2 DNA 超螺旋
    1. 細胞 DNA 是 underwound;聚合酶前方正、後方負超螺旋 p.21–23
    2. 計算:Lk₀ = bp/10.5 → ΔLk = Lk − Lk₀ → σ = ΔLk/Lk₀(細胞 −0.05~−0.07);負超螺旋 ⇔ Lk < Lk₀ 國考 p.25–30
    3. Lk 只有切斷再接回才會變:nick → 無定義;nucleosome 結合、加熱變性 → 不變 p.24–26, 52
    4. Underwinding 促成 cruciform(palindrome)與短段 Z-DNA p.31
    5. Topoisomerase(功能 = 切斷與接合磷酸雙酯鍵 國考)
      • Type I:切 1 股,Tyr 共價中間物,Lk ±1,不用 ATP p.33–35
      • Type II:切 2 股,Lk ±2,用 ATP p.33, 36
      • 細菌:topo I(Lk↑)、gyrase(ATP 引入負超螺旋,Lk↓)、topo IV(decatenation);真核只會鬆弛 p.34, 37
    6. 藥物:quinolone(擋接合)、coumarin(擋 ATP)→ 細菌;irinotecan、topotecan → topo I;doxorubicin、etoposide → topo II p.38–39
    7. Plectonemic(伸展右旋)vs solenoidal(緊密左旋,細胞內壓縮主力)p.42
  3. 24.3 染色體結構
    1. Chromatin = DNA + 蛋白(約等重)+ RNA;分化細胞多在 G0 國考 p.44–46
    2. Histone:鹼性(Arg+Lys ≈ 1/4);H3、H4 最保守 p.47
    3. Nucleosome:(H2A·H2B·H3·H4)×2 + 146 bp 纏 1.67 圈;重複 ~200 bp;H1 在 linker,不在 core 國考 p.49–51
    4. 真核 underwinding 的來源:纏 histone 的負超螺旋 + topo 鬆掉補償的正超螺旋 → ΔLk −1 p.52
    5. 組裝與變體:先 (H3–H4)₂ 後 H2A–H2B;CAF1(PCNA)、ASF1;H3.3、H2AZ、H2AX(Ser139)、CENPA;ChIP-seq 定位 p.53–55
    6. 高階結構:scaffold loops(topo II)→ TAD(~800 kb,CTCF)→ compartment → territory;lncRNA Xist 造 Barr body p.56–60
    7. SMC:cohesin(SMC1–3)綁姊妹、condensin(SMC2–4)凝縮、separase 切 cohesin p.61–63
    8. 細菌 nucleoid:~500 個 10 kb domain,HU 動態結合 p.64

24.1 染色體元件

  • 基因的演進:one gene–one enzyme(Beadle & Tatum)→ one gene–one polypeptide → 現代定義:編碼最終產物(polypeptide 或具結構/催化功能的 RNA)一級序列的全部 DNA p.5
  • Regulatory sequences:標記基因起訖、影響轉錄、作為複製或重組起點 p.5
  • Colinearity:一個 codon = 3 nt;350 個胺基酸(平均大小)需 1,050 bp 編碼 DNA p.6
  • DNA 遠長於包裝它的容器:λ phage 48,502 bp,contour length 17.5 µm;算法 3.4 Å/bp p.8
  • E. coli:一條環狀 dsDNA,4,641,652 bp,長 ~1.7 mm,約細胞長度 850 倍 p.7, 9
  • Plasmid:細胞質中小環狀 DNA(幾 kb 到 400,000 bp);帶 β-lactamase → 抗 penicillin、ampicillin、amoxicillin,可跨物種傳遞 p.9
  • 人類體細胞 46 條(22 對體染色體 + X、Y);一套基因體頭尾相接 ≈ 1 m,二倍體細胞 ≈ 2 m p.10
  • 人類 mtDNA:環狀 dsDNA,16,569 bp;每粒線體 2–10 copies;編碼粒線體 tRNA、rRNA 與少數蛋白;>95% 粒線體蛋白由核 DNA 編碼 p.11
  • mtDNA 的密碼系統和核 DNA 不完全相同 → 「完全相同」是錯的 國考 p.12–13
  • 植物 mtDNA 200,000–2,500,000 bp;cpDNA 120,000–160,000 bp;來源是古細菌的染色體 p.11
  • Intron(不轉譯的插入段)/ exon(編碼段);細菌基因很少有 intron;histone 基因沒有 intron p.14
  • Ovalbumin:7 個 intron 佔基因 85%;β-globin:2 個 intron p.14
  • 人類基因體只有 ~1.5% 是 exon;含 intron 的基因約佔 30%;transposon 約一半 p.14
  • Satellite DNA(= simple-sequence DNA = SSR):重複單位 <10 bp,約佔人類基因體 3%;CsCl 梯度中形成「衛星」帶;不編碼蛋白或 RNA;集中在 centromere、telomere p.15
  • Centromere:連接 mitotic spindle 的蛋白附著點,確保平均分離。酵母 ~130 bp、富含 A=T;高等真核是數千個 5–10 bp 重複 p.15
  • Telomere:(5')(TxGy)n;人類 (TTAGGG)n,哺乳類 n > 1,500;Tetrahymena TTGGGG p.16
  • 線性末端無法被一般機制完整複製 → telomerase 補:RNP reverse transcriptase,自帶 ~150 nt RNA 作模板,染色體 3' 端作 primer p.16–17
  • T loop + TRF1/TRF2 保護 3' 端;體細胞沒有 telomerase → 隨年齡變短 p.17
  • 穩定線性染色體只需 3 元件:centromere、兩端 telomere、replication origins(YAC 就是這樣做)。Primer 不是 國考 p.16, 18–19

24.2 DNA 超螺旋

  • Supercoiling = 螺旋再纏繞(coiling of a coil)。Relaxed DNA:DNA 軸沒有淨彎曲 p.21
  • 壓縮需中和磷酸負電:Mg²⁺、polyamines p.21
  • 細胞 DNA 是 underwound(每長度右旋圈數比 B-form 少)p.21, 23
  • 聚合酶前進:前方 overwound(正超螺旋)、後方 underwound p.22
  • 84 bp(8 圈)拿掉 1 圈 → 12 bp/turn,有張力;通常以超螺旋吸收(比打斷氫鍵便宜),或局部解開約 10 bp p.24
  • Underwound DNA = 儲存能量;只有閉環或被蛋白固定時才能維持,一個 nick 就鬆掉 p.24
  • Linking number (Lk):第二股穿過第一股所圍面的次數;拓樸性質,彎曲變形不變;永遠是整數;右旋為正 p.25
  • Lk 只有在「打斷再接回」骨架時才會改變;nick 一股 → Lk 無定義 p.23, 26

先問:Lk 有定義嗎?

  • Plasmid 在體內是負超螺旋 → Lk < Lk₀ 國考 p.29–30
  • Topoisomers:只差在拓樸性質(如 Lk)的同一環狀 DNA;切一股、轉 360°、接回 → Lk ±1 p.27
  • Underwinding 促進 cruciform(在 palindrome)與短段 Z-DNA;relaxed DNA 不利 cruciform p.31–32
  • Type I topo:切一股,Lk 每次變 1;Type II:切兩股,讓另一段雙股穿過,Lk 每次變 2 p.33
  • 電泳:超螺旋較緊密 → 跑得快;梯狀每一條帶是一種 topoisomer,相鄰差 Lk = 1 p.33
  • E. coli 至少 4 種:Topo I、III(type I)去除負超螺旋 → Lk 增加;DNA gyrase(type II)用 ATP 引入負超螺旋 → Lk 減少;Topo IV:decatenation(分開纏結的子染色體)p.34
  • 真核:type I = topo I、III;type II = IIα、IIβ;不能主動 underwind,只能鬆弛正、負超螺旋 p.34
  • Type I 機制:活性位 Tyr 攻擊磷酸雙酯鍵 → 5'-phosphotyrosyl 共價中間物 → 另一股穿過 → 3'-OH 攻擊接回;不需 ATP,淨 Lk +1 p.35
  • Type IIα:結合 2 ATP → 第一段雙股切斷 → 第二段穿過 → ATP 水解 → 接回,Lk 變 2 p.36
  • Reverse gyrase:用 ATP 產生正超螺旋,只在嗜熱菌;Topo IB = swivelase(所有真核)p.37
  • 真核怎麼變 underwound?纏 nucleosome 產生 bound 負超螺旋 + 補償的正超螺旋 → topo 把正的鬆掉 → 淨 ΔLk = −1 p.34, 52
  • Plectonemic:伸展、右旋、常分支,溶液中所見。Solenoidal:緊密左旋,靠蛋白穩定,細胞內主要壓縮方式;兩者都是負超螺旋,可互換 p.42
