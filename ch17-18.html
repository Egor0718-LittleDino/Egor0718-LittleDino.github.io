Ch17 · 17.1 脂肪的消化、動員與運送

  • 脂肪酸四個來源:飲食、儲存脂肪、肝合成、autophagy;人類 ≥ 40% 能量來自飲食 TAG Ch17 p.2
  • Bile salt(兩性分子)乳化 → mixed micelle → lipase 切成 DAG、MAG、FFA → 進小腸上皮 p.10
  • 上皮細胞重組 TAG → 包成 chylomicron:apoB-48 主要蛋白;apoC-II 活化 lipoprotein lipase;apoC-III 抑制;殘餘物把膳食膽固醇送到肝 → 包進 VLDL p.11
  • 脂解:glucagon / epinephrine → adenylyl cyclase → cAMP → PKA → perilipin 磷酸化 → CGI-58 離開去找 ATGL(TAG → DAG) → p-HSL(DAG → MAG) → MGL(MAG → FFA) p.13
  • Glycerol → 肝 glycerol kinase → glycerol 3-P → DHAP → 糖解 p.14
  • Serum albumin:約佔血清蛋白一半,非共價結合最多 7 個脂肪酸,送到骨骼肌、心、腎皮質 p.15
  • 活化:fatty acyl-CoA synthetase,ATP → AMP + PPi = 2 ATP p.16
  • ≤ 12 C 直接進粒線體;長鏈(≥ 14 C)走 carnitine shuttle:CPT1 → acyl-carnitine/carnitine 反向交換 → CPT2 p.17–18

  • 第 1 步三種 isozyme:VLCAD ≥ 12 C,在內膜;MCAD 約 4–14 C;SCAD 約 4–8 C(後兩者在基質) p.22
  • MCAD 缺乏:最常見;6–12 C 無法氧化 → 肝堆中鏈脂肪、血中 octanoic acid 高、低血糖 → 嗜睡、嘔吐、昏迷;治療:低脂高醣、不要空腹太久 p.23
  • Trifunctional protein(≥ 12 C):α4β4 在內膜;α = hydratase + HAD,β = thiolase;< 12 C 用四個可溶性酵素 p.27
  • 算 ATP:n 碳偶數 → (n/2 − 1) 輪、n/2 個 acetyl-CoA。每輪 4 ATP(1.5 + 2.5),每 acetyl-CoA 10 ATP,最後減 2。Palmitate = 28 + 80 − 2 = 106;stearate = 32 + 90 − 2 = 120 p.28–29
  • 單元不飽和(oleate):3 輪後得 cis-Δ3 → Δ3,Δ2-enoyl-CoA isomerase(hydratase 只認 trans) p.31
  • 多元不飽和(linoleate):再加 2,4-dienoyl-CoA reductase(trans-Δ2,cis-Δ4 → trans-Δ3) p.32
  • 奇數碳:剩 propionyl-CoA →(propionyl-CoA carboxylase,biotin、ATP)D-methylmalonyl-CoA →(epimerase)L 型 →(mutase,coenzyme B12)succinyl-CoA p.33
  • Propionic acidemia:carboxylase 缺乏 → propionyl-carnitine 出粒線體 → 血中 propionate 酸化;約 10 萬分之一 p.34
  • B12 只有微生物能做,每天約 3 μg;pernicious anemia = 缺 intrinsic factor 吸收不良 → 紅血球少 + 中樞神經損傷 p.35
  • Peroxisome β 氧化:第 1 步 acyl-CoA oxidase 直接給 O2 → H2O2(catalase 分解);處理極長鏈(26:0)與分支脂肪酸 p.36
  • Zellweger = 做不出 peroxisome;XALD = VLCFA 進 peroxisome 的運輸蛋白壞掉;Lorenzo's oil 抑制製造 VLCFA 的酵素 p.36
  • Phytanic acid 有甲基分支 → 不能 β 氧化 → peroxisome α 氧化(一次去 1 碳);Refsum = phytanoyl-CoA hydroxylase 缺陷 → 失明、失聰 p.37
  • PPARα(脂肪酸活化)開:脂肪酸運輸蛋白、CPT1/2、各長度 acyl-CoA DH;glucagon 經 cAMP/CREB;耐力訓練提高肌肉 PPARα p.38

Ch17 · 17.3 酮體

  • 缺 glucose 的情境:飢餓、糖尿病、生酮飲食;腦每天約 120 g glucose p.39–41
  • 肝以脂肪酸為主燃料,多的 acetyl-CoA → 酮體輸出 p.41
  • 肝粒線體合成:2 acetyl-CoA →(thiolase)acetoacetyl-CoA →(+ acetyl-CoA,HMG-CoA synthase)HMG-CoA →(HMG-CoA lyase)acetoacetate →(D-β-hydroxybutyrate DH)D-β-hydroxybutyrate;或脫羧成 acetone p.42
  • 肝外利用:β-hydroxybutyrate → acetoacetate →(thiophorase,用 succinyl-CoA 的 CoA)acetoacetyl-CoA → 2 acetyl-CoA p.43
  • 肝沒有 thiophorase → 只生產、不消耗酮體
  • 飢餓時腦用的酮體 = β-hydroxybutyrate p.44
  • 糖尿病:糖質新生耗光 oxaloacetate → TCA 卡住 → acetyl-CoA 變酮體;血中可達 90 mg/100 mL(正常 < 3),尿 5,000 mg/天 → ketoacidosis p.45

Ch18 · 18.1 胺基的去向

  • 胃:gastrin → parietal cell 分泌 HCl(殺菌、變性)+ chief cell 分泌 pepsinogen(自我活化成 pepsin) Ch18 p.5
  • 小腸:secretin → 胰臟分泌 bicarbonate(pH 升到約 7);cholecystokinin → 胰蛋白酶原 p.6
  • Enteropeptidase:trypsinogen → trypsin;trypsin 再活化其他。Trypsin 切 K/R、chymotrypsin 切 F/W/Y p.6
  • Acute pancreatitis = 酵素原在胰臟內提早活化,消化自己;pancreatic trypsin inhibitor 防止 p.6
  • 收集胺基的四個:Glu、Gln、Ala、Asp;肌肉送 Gln 與 Ala 到肝 p.9
  • Transamination:胺基給 α-KG → Glu + α-keto acid;PLP(B6)以 Schiff base 接 Lys,在 PLP / pyridoxamine phosphate 之間切換;Ping-Pong p.10–13
  • PLP 在 α 碳:transamination、racemization、decarboxylation p.12
  • Glutamate dehydrogenase(肝粒線體):Glu → α-KG + NH4+;NAD+ 或 NADP+;GTP 抑制、ADP 活化;GTP 位突變 → hyperinsulinism–hyperammonemia p.14
  • Glutamine 運氨(腦等);腎 glutaminase 在代謝性酸中毒時加速 → NH4+ 帶酸排出 p.15
  • Glucose–alanine cycle:肌肉 → alanine → 肝;把糖質新生的能量負擔交給肝 p.16
  • 氨毒性:NH3 過血腦障壁 → 困成 NH4+;星狀細胞 glutamine synthetase;NH4+ 與 K+ 競爭 → 神經功能異常、腦水腫 p.17

Ch18 p.20–23

  • Urea 兩個 N:NH4+(經 carbamoyl-P)+ Asp;C 來自 HCO3− p.21, 23
  • ORNT1:細胞質 ornithine 進、粒線體 citrulline + H+ 出(電中性) p.22
  • Ornithine 角色像 TCA 的 oxaloacetate;酵素組成 metabolon p.22–23
  • Aspartate–argininosuccinate shunt:fumarate → malate → TCA;粒線體做的 Asp 到細胞質給 N p.25
  • 調控:長期 = 高蛋白、飢餓時增加 4 個酵素 + CPS I;短期 = N-acetylglutamate(Glu + acetyl-CoA)活化 CPS I,Arg 活化 NAG synthase p.26
  • 能量:4 個高能磷酸鍵,fumarate 帶回 1 NADH(2.5),淨 1.5 ATP p.27–28
  • 缺陷 → hyperammonemia(腦水腫、昏睡、過度換氣);不能完全不吃蛋白(要必需胺基酸) p.29
  • Benzoate + Gly → hippurate;phenylbutyrate → phenylacetate + Gln → phenylacetylglutamine;都從尿排 p.30
  • NAGS 缺乏 → carbamoyl glutamate;OTC、ASS、ASL 缺乏 → 補 Arg;arginase 缺乏 → 禁 Arg p.31
