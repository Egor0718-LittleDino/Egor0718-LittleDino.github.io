9.0 複習:合成、PCR 與定序

講義 p.2–12 是 Ch8 後半的複習,內容與 Ch8 重疊。這裡只列 Ch9 版本多出來或講得更細的部分,完整內容見 Ch8 的 8.3。

  • PCR 原理:DNA polymerase 用模板和 dNTP 合成 DNA,只能把核苷酸加到既有股(primer)的 3′ 端 p.3
  • Sanger = dideoxy chain-termination;ddNTP 中斷合成 p.5
  • NGS 兩大類:reversible terminator(Illumina)與 SMRT(單分子即時)p.7–8
  • SMRT 平均讀長 30,000–40,000 bp p.11
  • Sequencing depth:基因體中某個核苷酸平均被定序的次數;contig:由重疊片段組裝出的長連續序列 p.12

9.1 研究基因與其產物

  • Clone = 完全相同的複製品;DNA cloning = 選擇性放大特定基因或片段,以便研究與利用;recombinant DNA technology(genetic engineering) = 達成這件事的各種方法 p.16

限制酶與接合

  • Restriction endonuclease:辨識特定序列(recognition sequence / restriction site)並切斷 DNA;methylase 甲基化宿主自己的 DNA 以免被切;兩者合稱 restriction-modification system p.21
  • Type I、III:大型多次單元複合體,同時具 endonuclease 與 methylase 活性。Type II:較簡單、不需 ATP、在辨識序列之內水解切斷 — 選殖用的是 type II p.22
  • Type II 辨識序列:通常 4–8 bp、palindromic(inverted repeat) p.23
  • 命名規則:三個字母的菌種縮寫 + 菌株代號 + 羅馬數字。BamHI = Bacillus amyloliquefaciens strain H 的第一個 p.23

  • Sticky end(黏性末端):交錯切,留下單股突出,互補的末端可自行配對 → 接合效率高、有方向性。Blunt end(平滑末端):對稱切,沒有突出 → 任何平滑末端都能接,但效率低、無方向性 p.24
  • 可用同一個 vector 同時以兩種酶切(如 EcoRI + PvuII),一端黏一端平,控制插入方向 p.24
  • Linker:人工合成的短 DNA,用來橋接要接合的末端;常帶 multiple cloning site(一段內含多個限制酶位點的序列)p.28

記憶點

和限制酶的分工
限制酶負責切並產生可配對的末端,ligase 負責把骨架接回去;只靠鹼基配對的黏性末端是鬆的,不接就會散開

取得要選殖的片段

  • 原核基因可直接用基因體 DNA 當模板;真核基因含 intron,直接用基因體 DNA 在細菌中表現會做不出正確蛋白 p.31–32
  • cDNA:以 mRNA 為模板、靠 reverse transcriptase 做出的雙股 DNA(已經沒有 intron);把 cDNA 片段放進 vector 選殖出的集合叫 cDNA library p.33
  • cDNA 合成:oligo(dT) primer 黏上 mRNA 的 poly(A) 尾 → reverse transcriptase 做出 mRNA–DNA 雜合 → 鹼降解 mRNA → DNA polymerase I 補成雙股 p.33
  • 用 PCR 取得片段時,目標序列內部不能有你要用的限制酶位點,否則目標會被從中間切斷;做法是把切點放在 primer 的非互補尾端,PCR 後再切 p.34

送入宿主與篩選

  • Transformation:用熱休克把小 plasmid 送進細菌;原因尚未完全清楚;plasmid 超過約 15 kb 後效率明顯下降 p.41
  • Electroporation:用高壓脈衝暫時讓細菌膜通透 p.41
  • Selectable marker:在特定條件下讓細胞活下來(positive selection)或死掉(negative selection),如 TetR、AmpR。Screenable marker:讓細胞產生有色或螢光分子的基因,如 lacZ p.44
流程:pBR322 的正負篩選(為什麼要兩個抗性) p.27, 45

表現選殖的基因、做出蛋白

  • 純化蛋白的用途:釐清功能、研究反應機制、製造抗體、在試管中重建複雜的細胞活性、找結合夥伴 p.53
  • Expression vector:除了選殖功能,還帶有調控表現所需的轉錄與轉譯訊號 p.54
  • 宿主選擇:細菌、酵母、昆蟲與昆蟲病毒、培養的哺乳類細胞 p.55
宿主優點缺點
細菌(最常用)調控序列清楚、表現量高、便宜好養、轉形與萃取方法成熟、可大量培養異源蛋白可能摺疊錯誤、沒有轉譯後修飾與蛋白切割、某些序列難表現、內在無序區聚集成inclusion body
昆蟲 / baculovirus可用 p10、polyhedrin 基因位置放入外源基因;bacmid 是能在 E. coli 中複製的大型環狀 DNA系統較複雜
哺乳類細胞可暫時或永久表現;轉譯後修飾正確非常昂貴
  • lac promoter 的調控是「leaky」(會漏);把基因接到 T7 promoter、由 T7 RNA polymerase 轉錄,才能得到嚴密調控。pET 系統:IPTG 使 lac repressor 脫落 → 宿主 DE3 上的 T7 RNA polymerase 被表現 → 再轉錄 pET 上的目標基因 p.57–58

改造選殖的基因

  • Site-directed mutagenesis:逐一置換特定胺基酸;oligonucleotide-directed mutagenesis:用帶突變的引子造成特定序列改變 p.62–63
  • 做法:變性 plasmid → 黏上帶突變的 oligo 引子 → DNA polymerase 延伸 → 用甲基化專一的核酸酶消化未突變的親代模板 → 轉形進細胞,由細胞修復 nick p.63
  • 經典例:RecA 的 Lys72 負責水解 ATP;K72R 突變體會結合 ATP 但不水解 — 用來分開「結合」與「水解」兩個步驟 p.64
  • Combinatorial(gene)library:聚焦在單一基因內序列變異的庫,可用 error-prone DNA polymerase 製造;DNA library 則是 DNA 選殖株的集合 p.65
  • 其他改造:用限制酶切掉一段再接回做 deletion;把兩個基因的部分接在一起,產物叫 fusion protein p.66

9.2 在細胞或個體層次探究蛋白功能

  • Comparative genomics:用基因體資料庫做比對來推定基因功能;BLAST 是快速搜尋的演算法;genome annotation 把序列轉換成「基因位置與功能」的資訊 p.76
  • Ortholog:不同物種之間,序列與功能有明確對應關係的基因。Paralog:同一物種內彼此相關的基因(來自基因重複)p.77
  • Synteny:基因順序在物種間保守;相關片段中位置相同的基因,是 ortholog 關係的額外證據 p.78
  • Structural motif:特定胺基酸序列對應特定結構模組,可推測分子功能,例如「會水解 ATP」「會結合 DNA」「會與鋅離子形成複合體」p.79

線索二、三:何時表現、在哪裡

  • RNA-Seq:判定在特定條件下基因體轉錄出哪些 RNA;scRNA-Seq 是靈敏度高到可做單一細胞的版本 p.81
  • GFP:與目標蛋白融合後可在活細胞中直接看位置;發色團由 Tyr-Gly-Ser 自行環化、脫水、氧化形成 p.82
  • Immunofluorescence:用抗體看內生蛋白,但需要固定細胞(細胞會死) — 這是它與 GFP 的主要差別。Epitope tag:一小段能被抗體緊密結合的蛋白序列 p.83

線索四:和誰互動

  • 兩類方法:純化蛋白複合體與 yeast two-hybrid analysis p.84
  • Immunoprecipitation:用對 epitope tag 的抗體,把融合蛋白(連同它帶著的夥伴)沉澱下來 p.85

線索五:CRISPR/Cas 與重要性

  • CRISPR = clustered, regularly interspaced short palindromic repeats p.89
  • 天然系統是細菌的免疫系統,三個組成:guide RNA(由存下的病毒間隔序列轉錄而來並被切出)、tracrRNA、一個以上的 Cas 蛋白;複合體結合入侵的噬菌體 DNA,由 Cas 的核酸酶活性摧毀它 p.91
  • 現行技術只需兩個組件:單一 Cas9 蛋白 + 單一 sgRNA(gRNA 與 tracrRNA 融合成一條 RNA)p.93
  • 切完之後的結果取決於修復方式:只有雙股斷裂 → NHEJ → 產生 frameshift 突變、插入終止密碼(knockout);另外提供 recombination fragment → HDR → 精準置換成指定序列 p.92
  • 用失去核酸酶活性的 Cas9 則可只定位不切,接上 repressor 做轉錄抑制(OFF)或接上 activator 做轉錄活化(ON)p.92, 97
  • High-throughput screening:建 sgRNA 寡核苷酸庫 → 選殖進 vector → 包成病毒 → 感染細胞 → 加選擇壓力 → PCR 放大 sgRNA 區域 → 深度定序,看哪些 sgRNA 被富集或消失 p.96
  • Positive screen:施加選擇後只有少數「贏家」存活,找出參與該選擇路徑的基因。Negative screen:多數細胞存活,用次世代定序找出消失的那些 p.97
  • 講義提醒:使用適當的正負對照是研究者自己的責任;投影片只是簡化概觀 p.97
  • 仍有許多蛋白未被發現、未知功能 p.95

p.101–102。蛋白編碼基因的功能分類中,unknown 佔 37.4% 最多,其次是 enzymes 16.2%、nucleic acid binding 9.8%、transcription factors 7.0%。

  • ENCODE 計畫:找出人類基因體中的功能性元件。結論是 >80% 的 DNA 會被轉錄成 RNA 或參與染色質結構的某種功能;剩下約 20% 中大多含有調控元件 p.103
  • SSR(simple-sequence repeat):高度重複、一般 <10 bp,約佔人類基因體 3%,集中在 centromere 與 telomere。Short tandem repeat:孤立的重複片段,常含數十個串聯重複 p.104
  • SNP:單一鹼基的變異;此外 deletion、insertion、rearrangement 也造成個體差異 p.105
  • Haplotype:通常會一起遺傳的一組 SNP;tag SNP:能代表整個 haplotype 的少數 SNP — 所以不必測全部 SNP 就能判定 haplotype p.106
  • 建構親緣樹可用的基因體差異:SNP、inversion、insertion、deletion、fusion、duplication p.107
  • Outgroup:親緣關係較遠的物種,用來判斷哪些序列改變是某一祖先支系獨有的 p.108
  • 部分 RNA 編碼基因顯示加速演化的證據,且在股配對處仍保留互補性 p.109
  • 已有 >6,000 種人類突變表型被定位到特定基因或基因群;Linkage analysis:把致病基因相對於已知多型性標記定位 p.110
  • 人類遷徙路徑可用現存族群中的 haplotype 追溯 p.112
