12.2 GPCR 與第二傳訊者

  • GPCR = 7 個跨膜螺旋 + G protein + effector;人類約 800 個;> 1/3 美國藥物打 GPCR;orphan receptor = 配體不明 p.14
  • Agonist 模仿、antagonist 阻擋;Kd:epinephrine 5 µM、isoproterenol(agonist)0.4、propranolol(antagonist)0.0046 p.17
  • β-adrenergic:epinephrine 結合 → 受體當 GEF,Gsα 換 GTP → Gsα·GTP 活化 adenylyl cyclase → cAMP → PKA → 磷酸化 → PDE 把 cAMP 變 5′-AMP 本課考題 Q21、Q22 p.18, 21–27
  • G protein 自帶 GTPase = 自我計時;RGS 加速 p.23
  • PKA:cAMP 結合 regulatory subunit → 移開自我抑制區;受質序列 x R [RK] x [S/T] B p.28
  • 放大:受體 → 多個 G → 多個 cAMP → PKA → phosphorylase b kinase → glycogen phosphorylase;cAMP 結合 PKA 那步不放大 本課考題 Q24 p.32–34
  • 四種關法:荷爾蒙離開、Gsα 水解 GTP(GAP/RGS)、cAMP PDE、phosphatase(PP1) p.35
  • 減敏:βARK 磷酸化受體 C 端 Ser → β-arrestin 結合 → 阻斷 G、內吞;去磷酸後回到表面 本課考題 Q23 p.36, 40
  • G protein 與 arrestin 不會同時結合;受體–arrestin 可啟動 MAPK;biased agonism(最易成癮的 opioid 偏 G 分支) p.39
  • 同一 cAMP 被很多荷爾蒙使用;PGE2 在脂肪耦合 Gi(降 cAMP),在其他組織耦合 Gs p.42–43
  • AKAP:抓住 PKA R 次單元,把 PKA 固定在特定位置 p.44
  • Ras:約 20 kDa;switch I Thr35、switch II Gly60;約 25% 癌症 Ras 突變失去 GTPase;NF1 = Ras GAP;Gsα 活化突變 → 約 40% 腦下垂體腺瘤;transducin 突變 → 夜盲 p.45–46
  • Cholera toxin:B 次單元接 ganglioside → A1 把 NAD+ 的 ADP-ribose 接到 Gsα 的 Arg → GTPase 失效 → cAMP 高 → PKA 開 CFTR → 腹瀉 p.49–50
  • cGMP:ANF(心房被撐)→ 膜型 guanylyl cyclase → 排鈉排水;NO(Arg,Ca2+ 依賴的 NO synthase)→ 可溶性含 heme 的 GC → PKG → 鬆弛;nitroglycerin 放 NO;sildenafil 抑制 cGMP PDE;E. coli 耐熱毒素打 guanylin 受體 p.53–54
  • Gq → PLCβ → PIP2 → DAG + IP3;IP3 開 ER 的 IP3-gated Ca2+ 通道;DAG + Ca2+ → PKC 本課考題 Q25 p.61, 72–74
  • 別混:PIP2 = 4,5-bisphosphate 脂質;PIP3 = PI3K 做的膜脂;IP3 = PLC 切下的水溶性頭基 p.62, 108
  • Calmodulin:4 個高親和力 EF hand;靜止 Ca2+ < 10^-7 M,刺激後約 10^-6 M p.75
  • Ca2+ 振盪:荷爾蒙濃度轉成頻率與幅度(Fura-2 測量);Ca2+ 訊號局部化 p.78

12.3 視覺、嗅覺、味覺

  • 視覺:光 → 11-cis 變 all-trans → rhodopsin → transducin 換 GTP → 移除 cGMP PDE 的抑制次單元 → cGMP ↓ → cGMP-gated Na+/Ca2+ 通道關 → 過極化 p.80
  • 恢復:transducin GTPase;低 Ca2+ 活化 guanylyl cyclase 補回 cGMP;rhodopsin kinase + arrestin 1;一個光子活化 ≥ 500 transducin p.82
  • 色盲:三種 cone opsin(約 420、530、560 nm);Dalton 的 DNA 證實 p.85
  • 嗅覺:約 800 個 GPCR → 嗅覺 G protein → adenylyl cyclase → cAMP-gated 通道;味覺:gustducin p.88

12.4 Receptor tyrosine kinase

  • INSR = (αβ)2;insulin 夾在兩個 α 之間 → β 互相磷酸化 3 個 Tyr → 活化環移開 p.94
  • 基因分支:INSR → IRS1(P-Tyr)→ Grb2(SH2 + SH3)→ Sos(GEF)→ Ras → Raf-1 → MEK → ERK → 進核 Elk1 → 約 100 個基因 p.95
  • MAPKKK(Raf-1,Ser/Thr)→ MAPKK(MEK,雙重專一 Ser/Thr + Tyr)→ MAPK(ERK) p.101
  • 代謝分支:IRS1-P → PI3K(PIP2 → PIP3)→ PKB(PDK1 活化)→ GSK3 失活 → glycogen synthase 活化;PKB → RAC1、Rab → GLUT4 上膜 p.103–104
  • PTEN 移除 PIP3 的 3 位磷酸;突變 → PIP3 高 → 分裂 p.108
  • 時間:受體、IRS 秒級 → ERK1 約 3 分 → GLUT4 約 15 分 → 基因數小時 p.109
  • 人類 58 個 RTK;多數單體,配體使其二聚 → 自我磷酸化;INSR 例外,永遠是二聚體 p.110
  • Cross talk:INSR(Tyr)與 PKB(Ser)磷酸化 β2 受體 → 內吞 → 對 epinephrine 不敏感 p.115

12.5 Adaptor 與 raft

  • SH2:P-Tyr(+1 到 +3 決定專一性);PTB:不同序列的 P-Tyr(IRS1);PH:PIP3;SH3:富 Pro 序列 p.117, 120
  • 自我抑制:Src 的 SH2 抓自己的 P-Tyr → 不活化,phosphatase 移除後活化;GSK3 的 pseudosubstrate p.118–119
  • Writer(kinase)/ reader(SH2、PTB、PH)/ eraser(phosphatase) p.120
  • KSR 支架抓住 Raf、MEK、ERK;ERK 回頭磷酸化 KSR → 負回饋 p.121
  • β-adrenergic 受體與 G、AC、PKA 在 raft 中;EGFR 集中在 caveolae p.122–123

12.6 閘控離子通道

  • Vm 約 −60 mV;Na+、Ca2+ 流入 → 去極化;K+ 流出 → 過極化 p.126
  • 動作電位:Na+ 通道開 → K+ 通道開 → 軸突末端 Ca2+ 通道開 → ACh exocytosis → ACh 開 ligand-gated 受體通道 p.127
  • Ionotropic(本身是通道)vs metabotropic(第二傳訊者);ACh、serotonin、glutamate 開陽離子通道;glycine、GABA 開 Cl− 通道 p.130
  • 毒素:tetrodotoxin → Na+ 通道;dendrotoxin → K+ 通道;cobrotoxin → ACh 受體 p.130

12.7 核受體

  • 類固醇隨血中蛋白運送 → 進細胞 → 核受體 → 二聚 → 結合 HRE → coactivator 或 corepressor → 數小時到數天 p.135
  • Tamoxifen 競爭 estrogen receptor(乳癌);RU486 阻斷 progesterone receptor(防著床) p.135

12.8 細胞週期

  • G1 → S(DNA 複製)→ G2 → M;G0 靜止;restriction point 後承諾分裂;培養細胞約 24 小時 p.139
  • Cyclin D–CDK4/6(G1)→ E–CDK2(G1/S) → A–CDK2(S、G2)→ B–CDK1(M) p.142
  • CDK2 活化:cyclin 結合(活性 ↑ 10,000 倍)+ Thr160 磷酸化 + Tyr15 去磷酸 p.143
  • 四種調控:磷酸化、cyclin 被 ubiquitin–proteasome 降解、生長因子 → Jun/Fos → E2F 增加合成、p21 等抑制劑 p.144
  • CDK 受質:lamin 磷酸化 → 核膜崩解;myosin;pRb p.147
  • 正常:cyclin E–CDK2 磷酸化 pRb → 放開 E2F → 複製基因 → G1 → S;DNA 損傷:ATM/ATR → p53 → p21 → 抑制 CDK2 → 停在 G1;太嚴重 → 凋亡 p.150

  • Retinoblastoma:遺傳一個壞 Rb → 每個細胞已中一擊 → 雙眼多發、年幼;Li–Fraumeni = 遺傳一個壞 p53;p53 在約 50% 癌症有缺陷 p.157
