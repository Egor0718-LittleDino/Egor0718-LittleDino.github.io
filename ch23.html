23.1 荷爾蒙的結構與作用

  • 荷爾蒙:一個組織製造 → 經血液 → 調控遠處組織 p.3
  • Epinephrine 同時是神經傳導物質與荷爾蒙 p.4
  • 受體親和力高 → 極低濃度就有效;第二傳訊者放大:1 個 epinephrine → 數百萬個 glucose 1-P p.5
  • 不溶於水(steroid、thyroid)→ 進細胞 → 核受體 → 改基因表現,慢(小時到天);水溶性 → 膜受體 → 快 p.5–6
  • 膜受體:metabotropic 調控酵素;ionotropic 開關離子通道 p.5
  • Endocrine 進血液(insulin、glucagon);paracrine 鄰近細胞(eicosanoid);autocrine 作用在自己 p.7
  • 胜肽荷爾蒙常先做成無活性 prohormone,再切割活化(TRH 很小、hCG 很大) p.8
  • Insulin:MW 5,800,A、B 兩鏈;preproinsulin →(去 signal sequence、形成 3 個 disulfide)proinsulin(存在 β 細胞顆粒)→(切 2 個胜肽鍵)insulin + C peptide 一起 exocytosis p.9
  • POMC:一個前驅蛋白含 ≥ 9 個活性胜肽;各組織蛋白酶不同 → 切出不同荷爾蒙 p.10
  • Top-down:下視丘 CRH → 腦下垂體 ACTH → 腎上腺皮質 cortisol;逐級放大約百萬倍,每級回饋抑制 p.11–12
  • Bottom-up:脂肪(leptin 抑食、adiponectin)、胃(ghrelin 促食)、腸(GLP-1 促 insulin 分泌、GIP 抑 glucagon) p.13

23.2 各組織的代謝分工

組織燃料與特徵頁
肝經門脈第一站;GLUT2 + glucokinase(Km 高、不被 G6P 抑制);有 glucose 6-phosphatase 可輸出 glucose;主要燃料 = 脂肪酸;做酮體但不用;合成多數血漿蛋白;P-450 解毒;酵素周轉快p.15–22
白色脂肪一個大油滴;epinephrine 促進脂解、insulin 抑制p.23
棕色、米色脂肪多個小油滴、大量粒線體;UCP1 讓 H+ 繞過 ATP synthase → 產熱;irisin(運動肌肉分泌)促成米色脂肪p.24–25
骨骼肌慢縮(紅、有氧、耐疲勞)/快縮(白、力大易疲勞);靜止用脂肪酸;全力時 glycogen → lactate,每葡萄糖單位 3 ATPp.26–27, 36
心肌完全有氧,粒線體約佔一半體積;主要用游離脂肪酸;phosphocreatine 少 → 缺血就梗塞p.32
腦佔體重 2%、用掉約 20% 靜息耗氧;平常只用 glucose,glycogen 極少;不能用脂肪酸;長期禁食最多 60% 能量來自 β-hydroxybutyratep.33
紅血球沒有細胞核、粒線體 → 只靠糖解,lactate 回肝p.34
  • 肝內 G6P 五條路:去磷酸輸出 glucose、做 glycogen、糖解成 acetyl-CoA、合成脂質、PPP(NADPH + ribose 5-P) p.17
  • 肝處理胺基酸:合成蛋白 → 多的轉胺或脫胺 → pyruvate / TCA 中間物 → 糖質新生;NH3 → urea p.18–19
  • Glucose–alanine cycle:肌肉胺基 + pyruvate → alanine → 肝:pyruvate 做糖、NH3 做 urea p.20
  • 血中脂質:脂蛋白送到脂肪;游離脂肪酸靠 albumin 送到心、肌肉 p.22
  • Creatine kinase:mCK 把 ATP 當量以 phosphocreatine 送出粒線體;cCK 在用 ATP 的地方再生 ATP p.28–29
  • 臨床:creatinine ↑ = 腎功能差;CK-MB(心肌獨有)出現在血中 = 心肌受損 p.30
  • Cori cycle:肌肉 lactate → 肝糖質新生 → glucose 回肌肉補 glycogen;運動後喘氣是在給肝氧 p.31
  • Shivering thermogenesis:肌肉快速收縮維持 37°C p.31
  • 血糖正常 60–90 mg/100 mL(約 4.5 mM);約 70 開始低血糖 → 混亂 → 昏迷 p.35, 37
  • 算:從 glucose 糖解淨 2 ATP;從 glycogen 淨 3 ATP(少花一個 ATP) p.36

23.3 燃料代謝的荷爾蒙調控

荷爾蒙訊號主要作用頁
Insulin(β)血糖高GLUT4 上膜(肌肉、脂肪);肝 glycogen synthase ↑、phosphorylase ↓;多餘 glucose → 脂肪酸 → TAG → VLDL → 脂肪儲存p.38–39
Glucagon(α)血糖低肝:cAMP → fructose 2,6-bisphosphate ↓、pyruvate kinase ↓ → 糖解 ↓、糖質新生 ↑、glycogen 分解 ↑;脂肪:perilipin、HSL 磷酸化 → 脂解p.43
Epinephrine(腎上腺髓質)即將劇烈活動肌肉 glycogen 分解與糖解 ↑、脂肪動員;glucagon ↑、insulin ↓;心跳、血壓、呼吸道擴張p.47
Cortisol(腎上腺皮質)長期壓力、低血糖慢,改酵素合成;肌肉蛋白分解 → 肝糖質新生;脂肪酸釋出p.48
  • 胰島:α = glucagon、β = insulin、δ = somatostatin p.40
  • Insulin 分泌:glucose → GLUT2 → glucokinase → ATP ↑ → ATP-gated K+ 通道關 → 去極化 → voltage-gated Ca2+ 開 → exocytosis p.41
  • 副交感促進、交感抑制;血糖降 → glucokinase 活性降 → 分泌減少(自我回饋) p.41
  • K+ 通道 = Kir6.2 + SUR1 八聚體;sulfonylurea 結合 SUR1 → 關通道 → 分泌 insulin p.42
  • Kir6.2 突變、通道一直開 → neonatal diabetes(要打 insulin);通道永遠關 → 持續分泌 → 嚴重低血糖 → 部分胰臟切除 p.42
  • 三種儲備:肝與肌肉 glycogen、脂肪 TAG、組織蛋白;正常體重成人 TAG 撐約 3 個月,肥胖者超過 1 年 p.44
  • 禁食時程:2 小時用肝 glycogen → 4 小時 glucagon ↑、TAG 動員 → 長期:蛋白分解、生糖胺基酸做糖給腦 → oxaloacetate 用光 → acetyl-CoA 變酮體 → 數天後心、肌肉、腦用酮體 p.45
  • Cushing = 腦下垂體腫瘤 → cortisol 過多;Addison = cortisol 不足 → hydrocortisone p.48

23.4 肥胖與體重調控

  • BMI > 30 肥胖、> 40 嚴重肥胖;美國 > 40% 成人肥胖 p.49
  • Adiposity negative-feedback:超過 set point → 抑食、增加消耗;leptin(1994)是第一個找到的 adipokine p.50
  • OB 基因 = leptin;DB 基因 = leptin receptor。ob/ob 打 leptin 有效;db/db 無效 p.51–52
  • Leptin → 交感神經 → 血壓、心跳 ↑;norepinephrine → UCP1 轉錄、粒線體增加 → 產熱 p.52, 54
  • 弓狀核:NPY = 促食慾(饑餓、ob/ob、db/db 時高);α-MSH = 抑食慾(來自 POMC) p.53
  • 減重 → leptin ↓ → NPY ↑、產熱 ↓ → 想吃回來 p.53
  • 人類肥胖多半 leptin 很高 = leptin resistance;打 leptin 只對少數基因缺陷者有效 p.54
  • Adiponectin → 經 AMPK:肌肉脂肪酸攝取與 β 氧化 ↑;肝脂肪酸合成、糖質新生 ↓;insulin 敏感性 ↑ p.55
  • AMPK:[AMP]/[ATP] 高就開;LKB1 磷酸化放大;關脂肪酸、膽固醇合成;metformin;在下視丘整合 ghrelin、adiponectin、leptin p.56
  • mTORC1:Rag G 蛋白感應胺基酸 → 招到 lysosome;Rheb-GTP 活化 → 合成蛋白、脂質、粒線體;禁食時被 AMPK 關掉;長期過度活化 → insulin resistance、癌症 p.57
PPAR(與 RXR 配對)作用頁
PPARγ纖維母細胞 → 脂肪細胞分化、脂質儲存;TZD 標靶p.59
PPARα肝、腎、心、肌肉、棕色脂肪;禁食時脂肪酸攝取、β 氧化、酮體p.59
PPARδ肝、肌肉 β 氧化與粒線體 uncoupling → 減重、產熱p.59
  • Ghrelin:胃、餐前高、GPCR;Prader-Willi ghrelin 很高 → 食慾失控 p.61
  • PYY3–36:小腸結腸、餐後高、抑制 NPY,效果最長 12 小時 p.61
  • Endocannabinoid:eicosanoid 類、GPCR、增加食慾(尤其脂肪)、促進脂肪堆積;THC 作用在同受體 p.62

23.5 糖尿病

Type 1(IDDM)Type 2(NIDDM)
原因自體免疫破壞 β 細胞 → insulin 不足insulin resistance;早期 β 細胞多分泌代償,後來衰退
發病早、症狀重慢、常見於肥胖成人
治療insulin + 終身管理飲食、運動、藥物、手術

p.63–64, 67

  • 兩型共同點:GLUT4 無法有效上膜 → glucose 進不了肌肉、脂肪 p.65
  • 診斷:HbA1c(平均血糖);glucose tolerance test(空腹喝 100 g)→ 糖尿病:升很高、降很慢、超過腎閾值 → 尿糖 p.65
  • Ketoacidosis:脂肪酸變主燃料 → [NADH]/[NAD+] 高 → acetyl-CoA 進不了 TCA → 酮體 ↑(ketonemia、ketonuria)→ 酸超過 bicarbonate 緩衝 p.66
  • Metabolic syndrome:腹部肥胖、高血壓、TAG 與 LDL 高、HDL 低、空腹血糖略高、fibrinogen 與 CRP 高;美國約 30% 成人 p.67
  • Lipid toxicity:脂肪細胞裝滿 → MCP-1 招巨噬細胞(可達 50%)→ TNFα → 儲存能力壞掉 → 脂肪酸進血 → 肝、肌肉異位脂肪 → GLUT4 上不了膜 → insulin resistance p.68
  • 80% 第二型患者肥胖,但多數肥胖者不會得 → 基因(diabetogenes)× 環境;adiponectin 肥胖時降、減重時升 p.69
  • 運動:燃熱量、irisin → 白色脂肪 UCP1 → 米色脂肪、活化 AMPK;藥物標靶 AMPK、β 細胞 K+ 通道、PPAR、GLP 受體 p.70
  • Roux-en-Y gastric bypass:胃縮成小囊接空腸;除減重外,改變 GLP-1、PYY3–36 → 飽足,常逆轉第二型糖尿病 p.71

講義前後不一致:p.13 寫 adiponectin「stimulates feeding」,p.55 則說它經 AMPK 提高 insulin 敏感性;題目只考 p.55 的說法。
